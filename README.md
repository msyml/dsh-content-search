# DSH 工作区内容搜索

本插件为 DSH 0.2.2-rc.1 提供工作区内容搜索：按 Ctrl+F，输入要查找的文字，可用文件包含规则限制范围，使用上下方向键选择匹配行，回车将该文件的 `@路径` 插入当前输入框；Escape 关闭。插件不自动发送消息，不上传文件。

## 使用范围和规则

- 搜索当前会话的工作区根目录，非后来通过 `working_directory` 切换的目录。
- 按文本字面匹配，默认不区分大小写；不是正则搜索。
- 文件包含规则支持逗号分隔的 basename glob（例如 `*.ts, *.md`）或相对于根的路径 glob（如 `src/**/*.ts`）。支持 `*`、`?` 和整段 `**`；不支持 `!` 排除规则、花括号与字符类。
- 默认排除名为 `.git`、`.hg`、`.svn`、`node_modules`、`build`、`dist`、`coverage`、`.next`、`.cache` 的目录（包括同名的源码目录）；不读取 `.gitignore`。不处理明确标识为符号链接的条目，但某些文件系统可能将目录链接报告为目录；搜索仍受目录数量和时间上限约束。
- 搜索上限为 30000 个目录、200000 条目录项、20000 个文件、80000 个文件页、500 条匹配、单文件 256 KiB、120 秒；目录接口自身每目录最多 2000 条。搜索过程中逐步显示结果，达到上限或超时会提示并保留已完成的结果。搜索使用 DSH 现有的会话工作区访问接口，并受其授权约束，不保证覆盖完整项目。
- 插入的是 `@路径` 纯文本引用，不是原子引用胶囊，也不是文件上传。文件名含空格时使用带引号的引用。输入位置或者会话变化时，插件不应覆盖草稿。
- 先将焦点放在当前对话输入框，再按 Ctrl+F（macOS 用 Command+F）打开。快捷键只在该输入框内生效，不占用 DSH 全局快捷键；其他输入框、侧边栏编辑器和终端沿用各自行为。浏览器中使用 Ctrl+F 时仍可能受浏览器快捷键处理影响。该局部快捷键暂不能在 DSH 的快捷键设置中改键。

## 测试与构建

```sh
npm test
npm run build
```

插件为独立包，不修改 DSH 安装目录。安装需选择当前使用的 profile。安装前请备份原有配置，并核验插件版本和构建产物。
