# DSH 工作区内容搜索

本插件为 DSH 0.2.2-rc.1 提供工作区内容搜索：在 better-sidebar 右侧栏的“+”菜单中打开“内容搜索”，也可将焦点放在当前对话输入框后按 Ctrl+F（macOS 用 Command+F）打开弹窗。输入要查找的文字，可用文件包含规则限制范围，勾选“全词匹配”只匹配完整单词；使用上下方向键选择匹配行，回车或点击结果将该文件的 `@路径` 插入当前输入框；Escape 关闭弹窗。插件不自动发送消息，不上传文件。

## 使用范围和规则

- 搜索当前会话的工作区根目录，非后来通过 `working_directory` 切换的目录。
- 按文本字面匹配，默认不区分大小写；勾选“区分大小写”后按大小写精确匹配；勾选“全词匹配”后按 Unicode 字母、组合标记、数字和下划线识别词边界（标点和连字符为边界）；不是正则搜索。
- 文件包含规则支持逗号分隔的 basename glob（例如 `*.ts, *.md`）或相对于根的路径 glob（如 `src/**/*.ts`）。支持 `*`、`?` 和整段 `**`；不支持 `!` 排除规则、花括号与字符类。
- 默认排除名为 `.git`、`.hg`、`.svn`、`node_modules`、`build`、`dist`、`coverage`、`.next`、`.cache` 的目录（包括同名的源码目录）；不读取 `.gitignore`。不处理明确标识为符号链接的条目，但某些文件系统可能将目录链接报告为目录；搜索仍受目录数量和时间上限约束。
- 搜索上限为 30000 个目录、200000 条目录项、20000 个文件、80000 个文件页、500 条匹配、单文件 256 KiB、120 秒；目录接口自身每目录最多 2000 条。搜索过程中逐步显示已找到结果数和已检查文件数，达到上限或超时会提示并保留已完成的结果。搜索使用 DSH 现有的会话工作区访问接口，并受其授权约束，不保证覆盖完整项目。
- 插入的是 `@路径` 纯文本引用，不是原子引用胶囊，也不是文件上传。文件名含空格时使用带引号的引用。侧边栏插入时需要目标会话的输入框已挂载（通常是当前会话）；若会话或草稿发生变化，插件不会覆盖草稿。
- 先将焦点放在当前对话输入框，再按 Ctrl+F（macOS 用 Command+F）打开弹窗；搜索也可以在 better-sidebar 右侧栏的“+”菜单中打开“内容搜索”。快捷键只在输入框内生效，不占用 DSH 全局快捷键；其他输入框、侧边栏编辑器和终端沿用各自行为。浏览器中使用 Ctrl+F 时仍可能受浏览器快捷键处理影响。该局部快捷键暂不能在 DSH 的快捷键设置中改键。侧边栏搜索结果可用 Tab 聚焦结果列表，再按 ↑↓ 选择、Home/End 跳到首尾、Enter/空格插入引用；插入要求目标会话当前仍有可用输入框。

## 测试与构建

```sh
npm test
npm run build
```

插件为独立包，不修改 DSH 安装目录。安装需选择当前使用的 profile。安装前请备份原有配置，并核验插件版本和构建产物。
